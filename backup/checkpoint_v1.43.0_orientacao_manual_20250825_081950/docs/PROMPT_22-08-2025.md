## ⚠️ O PROBLEMA PENDENTE (FOCO TOTAL)

O problema atual é ao iniciar uma navegação para um POI o robô tenta se ajustar para a direção do destino do POI. Essa tentativa de se ajustar para direção do POI é realizada com uma força ás vezes um pouco maior que o necessário e deixando a direção inicial do robô às vezes levemente para esquerda ou para direita. O sistema pega essa posição(levemente inclinada para esquerda ou direita) como a posição inicial e inicia a navegação e causando uma navegação levemente em disgonal para um lado ou para o outro, conforme o robô ficou inicialmente direcionado. penso que seja a força dessa tentativa de direcionamento. Mas temos algumas situações que o robô consegue se direcionar corretamente para o POI e a navegação é perfeita. A distância percorrida é perfeita. A velocidade está muita boa.
Sugestão para análise da IA: 
1) como já existe uma ROBOT_INITIAL_POSITION = (5.7, 11.5) # (x, y) e uma ROBOT_INITIAL_ANGLE = 270   e o robô será sempre posicionado manualmente nessa posição inicial, essa tentativa do robô em se posicionar em direção ao alvo POI não deveria nem existir pois o usuário sabe a posição OBRIGATÓRIA que o robô deve ficar inicialmente. Temos as situações nas quais o POI pode não está exatamente numa direção/posição em linha reta da base inicial do robô mas acredito que um percurso em diagonal o robô vai conseguir fazer ou se for o caso podemos criar uma iniciação da nevagação mais suave mas com força suficiente para mover o robô. 

### TESTES REALIZADOS:
Realizamos 30 testes com o mesmo percurso (POI) e o resultado foi que em 27 vezes o robô navegou e concluiu o percurso com o sistema informando da navegação concluida. Importante saber que nessas 27 testes tivemos navegação perfeitamente atingindo o alvo(POI) e às vezes desviando-se um pouco do alvo para direita e/ou para esquerda conforme a direção que ele ficou ao iniciar a navegação.
3 testes o robô ficou em loop de 360 graus sen iniciar a navegação.
