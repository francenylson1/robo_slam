# Prompt - 11/08/2025: Próximos Passos do Projeto

## O projeto é de um robô garçom desenvolvido em Python, Raspberry, dois motores, pacotes de odometria e tecnologia SLAM, PyQt5, etc. O robô navega para pontos de interesse conforme seleção pelo usuário. Ele vai até o destino, se corrigindo se necessário, para se alinhar ao ponto de interesse final. Chagando ao ponto destino vamos fazer um giro de direcionamento para o novo destino ou para base inicial de maneira "manual" pelo usuário.

## Estágio Atual do Projeto

O projeto atingiu um marco de estabilidade significativo. O versionamento foi reestruturado para um fluxo de trabalho profissional utilizando as branches `main` (para versões estáveis) e `develop` (para desenvolvimento contínuo).

-   **`main`**: Contém a versão `v1.35`, que possui navegação funcional e se tornou nossa base estável. O ambiente na Raspberry Pi está sincronizado com esta branch.
-   **`develop`**: É a nossa branch de trabalho para novas implementações. O ambiente no desktop está nesta branch.
-   **Documentação**: Um tutorial detalhado do fluxo de trabalho Git (`Tutorial_Versionamento_Git.md`) foi criado para guiar o desenvolvimento futuro.

Com a casa em ordem, estamos prontos para iniciar um novo ciclo de desenvolvimento de funcionalidades.

## Estágio atual do projeto
1. Mapa de teste;
2. Módulo de pontos de interesse em funcionamento com crição de pontos de interesse e exclusão de pontos de interesse;
3. Módulo de áreas proibidas em funcionamento com criação e exclusão de áreas proibidas;
4. Navegação com destino a ponto de interesse selecionado;
5. Robô da interface e robô físico em sincronia de movimentos na navegação : direita do robô da interface = direita do robô físico, etc;
6. O robô navega até o ponto de interesse(destino) em linha reta ou fazendo pequenas/leves curvas, se corrigindo para chegar ao destino final corretamente;

## Funcionalidades a Implementar

As seguintes funcionalidades serão desenvolvidas na branch `develop`, seguindo o fluxo de trabalho documentado.

1.  **Botões de Navegação Manual para Retorno à Base**: Adicionar botões na interface para controle manual dos giros do robô. Isso será usado especificamente durante a manobra de retorno à base para alinhar o robô com a posição base inicial fixa. Crie botões pequenos e responsivos com os sinais de left, right, forward, para trás.

2.  **Sincronização da Interface Durante Giros Manuais**: Garantir que, ao usar os botões de giro manual, a representação do robô na interface gráfica (mapa) reflita com precisão a orientação real do robô físico.

3.  **Criação de Novos Mapas**: Implementar a funcionalidade que permite ao usuário criar, salvar e carregar diferentes mapas para o robô operar.


4.  **Reconfigurar Retorno Automático à Base**: Modificar a lógica de "retorno à base". A função automática cuidará apenas do percurso (movimento para frente), enquanto a orientação final (o giro para encaixar na base) será de responsabilidade do operador através dos novos botões manuais. Ou seja, utilizar a função de navegação que chega até o ponto de interesse que já está funcionando;

5.  **Interface Responsiva (Mobile)**: Adaptar a interface do usuário para que seja funcional e esteticamente agradável em telas menores, como as de smartphones, permitindo o controle e monitoramento do robô remotamente.
