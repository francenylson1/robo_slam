--------------------------------------------------------------------------------
OBJETIVO DESTA VERSÃO
--------------------------------------------------------------------------------
Navegação SEMI-AUTOMÁTICA: operador com joystick; o robô usa BNO08x para manter
linha reta ao comando “frente”, compensando deriva mecânica (motores, rodas,
piso liso, desgaste). Não confundir com navegação autônoma até POIs (track 2).

Requisitos funcionais alinhados ao produto:
- Frente/ré proporcional (analógico); em modo “reto” (eixo lateral pequeno),
  BNO corrige yaw para trajetória retilínea.
- Curvas: mecanismo de graus por clique (ex.: D-pad / botões); atalho para
  giro de ~180° (menos cliques, mais previsível).
- Conflito histórico BNO × odometria na navegação AUTÔNOMA levou a USE_BNO_IN_
  NAVIGATION=False na track autônoma. AQUI, no modo joystick, o BNO é o eixo
  de correção em reta — sem fundir BNO na pose global do navegador POI.

FASE POSTERIOR (só depois de semi-automático estável — não misturar no escopo atual):
- Voz operador ↔ público (microfone remoto); webcam; avatar olhos/boca no display 7".

--------------------------------------------------------------------------------

  flags --no-bno, --identify, --tps; D-pad com graus por clique (DPAD_TURN_DEG).
- src/main.py — inicia só a MainWindow PyQt5 (modo “aplicativo garçom”); não há

- src/core/robot_motor_controller.py — PWM/TPS, fatores L/R, integração C1,

- Documentação útil: docs/REVISAO_BNO_LINHA_RETA.md, docs/NAVEGACAO_ODOMETRIA_

--------------------------------------------------------------------------------
SUGESTÃO DE LAUNCHER (main / UX) — alinhar implementação nesta branch
--------------------------------------------------------------------------------
Objetivo: um único comando na Pi e no desktop, com escolha explícita de modo.

Opção A (recomendada): argumentos de linha de comando + espelho na GUI
  python src/main.py --mode autonomous   # comportamento atual (mapa/POIs)
  python src/main.py --mode joystick     # UI ou painel mínimo + teleop BNO
  Sem flag: exibir diálogo inicial (PyQt) “1) Autônomo  2) Joystick” e então
  fluxo de mapa/arquivo se aplicável ao modo autônomo; joystick pode reutilizar
  o mesmo PGM só para visualização ou tela reduzida.

Opção B: dois executáveis finos que chamam módulos compartilhados (mais manutenção).

Regra de produto: mesmo com autonomia madura, o robô DEVE continuar oferecendo
modo semi-autônomo com joystick.
