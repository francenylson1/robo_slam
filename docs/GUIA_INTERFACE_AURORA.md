# 🗺️ Guia: Navegar na Interface Web do Aurora

## Onde Encontrar a Exportação de Mapas

A interface do Aurora pode variar, mas geralmente o mapa está em um destes locais:

### 📍 Locais Comuns para Encontrar Mapas

#### 1️⃣ **Menu Principal / Navegação Superior**
Procure por:
- **"Map"** ou **"Mapa"**
- **"Mapping"** ou **"Mapeamento"**
- **"SLAM"**
- **"Navigation"** ou **"Navegação"**

#### 2️⃣ **Menu Lateral (Sidebar)**
Se houver um menu lateral, procure por:
- **"Maps"** (ícone de mapa)
- **"Saved Maps"** ou **"Mapas Salvos"**
- **"Map Library"** ou **"Biblioteca de Mapas"**

#### 3️⃣ **Dashboard Principal**
Na página inicial, procure por:
- **Card ou botão "Maps"**
- **Lista de mapas recentes**
- **Área mostrando o mapa atual**

#### 4️⃣ **Menu de Configurações**
Às vezes está em:
- **"Settings"** → **"Maps"**
- **"Configuration"** → **"Map Management"**

### 🔍 O Que Procurar Visualmente

Procure por:
- 📍 **Ícone de mapa** (geralmente um mapa/mundo)
- 📥 **Ícone de download** (seta para baixo)
- 💾 **Ícone de salvar/exportar**
- 📋 **Lista de arquivos/mapas**

### 📋 Passo a Passo Detalhado

1. **Olhe para o topo da página**
   - Há um menu horizontal? Clique em "Map" ou "Maps"

2. **Olhe para o lado esquerdo**
   - Há um menu vertical? Procure por "Maps" ou "Mapping"

3. **Olhe no centro da página**
   - Há uma visualização do mapa?
   - Há botões ao redor do mapa?
   - Procure por "Export", "Download", "Save"

4. **Procure por uma lista de mapas**
   - Se houver uma lista, clique no mapa desejado
   - Depois procure por opções de exportação

### 🎯 Quando Encontrar a Lista de Mapas

Você deve ver algo como:
- Lista de mapas salvos
- Nomes como "sala-maker-1", "map_001", etc.
- Botões ao lado de cada mapa:
  - **"Export"** ou **"Exportar"**
  - **"Download"**
  - **"Save As"** ou **"Salvar Como"**
  - **Três pontos (...)** → menu com opções

### 📤 Ao Clicar em Export/Download

Você deve ver opções de formato:
- ✅ **PLY** (Point Cloud)
- ✅ **PCD** (Point Cloud Data)  
- ✅ **BMP** ou **PNG** (Imagem 2D)
- ⚠️ **STCM** (formato proprietário)

**Escolha PLY ou PCD se disponível!**

### 🆘 Se Não Encontrar

1. **Tire uma captura de tela** da interface
2. **Descreva o que você vê** na página inicial
3. **Liste os menus** que aparecem

Com essas informações, posso te guiar mais especificamente!

### 💡 Dica

Algumas interfaces do Aurora têm:
- **Botão de menu (☰)** no canto superior esquerdo
- **Ícone de engrenagem (⚙️)** para configurações
- **Barra de busca** para procurar "map" ou "export"
