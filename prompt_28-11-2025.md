## 🔄 FLUXOGRAMA COMPLETO DO PIPELINE C1 MAPPING

```
┌─────────────────────────────────────────────────────────────────┐
│                    C1 MAPPING STUDIO                            │
│                    Pipeline: C1 USB → Mapa Final                │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────┐
│  INPUT: C1 USB  │  Sensor Slamtec C1 conectado via USB
│  (Hardware)     │
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────┐
│  ETAPA 1: CAPTURE                                               │
│  └─ c1_usb_client.py + scan_collector.py                       │
│     • Detecta C1 via USB                                        │
│     • Inicializa comunicação com sensor                         │
│     • Coleta varreduras LIDAR (scans)                           │
│     • Armazena dados brutos (timestamp, ângulos, distâncias)    │
│     • Interface para iniciar/parar captura                      │
└────────┬────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────┐
│  ETAPA 2: SLAM PROCESSING                                       │
│  └─ slam_processor.py + map_builder.py                         │
│                                                                  │
│  CENÁRIO 1 (MAIS PROVÁVEL): C1 tem SLAM interno                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 2.1. Usa API do C1 para obter mapa já processado        │  │
│  │ 2.2. Baixa mapa via c1_map_reader.py                    │  │
│  │ 2.3. Mapa já vem em formato PGM/YAML                    │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                  │
│  CENÁRIO 2 (MENOS PROVÁVEL): C1 não tem SLAM interno           │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 2.1. Processa varreduras coletadas                       │  │
│  │ 2.2. Aplica algoritmo SLAM 2D (Gmapping ou similar)      │  │
│  │ 2.3. Constrói mapa de ocupação incremental               │  │
│  │ 2.4. Gera occupancy grid 2D                              │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────┬────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────┐
│  ETAPA 3: REFINEMENT                                            │
│  └─ map_cleaner.py + map_optimizer.py + noise_reduction.py     │
│     • Remove ruído e outliers                                   │
│     • Preenche pequenos buracos (morphology)                    │
│     • Dilatação/erosão para ajustar obstáculos                  │
│     • Otimização de resolução                                   │
│     • Validação de qualidade do mapa                            │
└────────┬────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────┐
│  ETAPA 4: EXPORT                                                │
│  └─ pgm_exporter.py + bmp_exporter.py + format_converter.py    │
│     • Exporta PGM + YAML (formato padrão)                       │
│     • Exporta BMP (visual, para interface)                      │
│     • Gera metadados (resolução, origem, etc.)                  │
│     • Salva em formato compatível com main.py                   │
└────────┬────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────┐
│  OUTPUT:        │  Mapa pronto para uso:
│  Mapa Final     │  • .pgm/.yaml (técnico)
│                 │  • .bmp (visual)
│                 │  • Metadados
│                 │  • Compatível com main.py
└─────────────────┘
```

**Abordagem**:
1. Conectar C1 via USB
2. Usar API do C1 para iniciar mapeamento
3. Coletar mapa já processado via API
4. Aplicar refinamento (limpeza, otimização)
5. Exportar PGM/YAML/BMP

**Vantagens**:
- Mais simples (não precisa implementar SLAM)
- Mais rápido (C1 já processa)
- Mais confiável (SLAM otimizado pelo fabricante)

**Implementação**:

- Criar módulo de refinamento
- Criar módulo de exportação

### Cenário 2: C1 não tem SLAM interno (MENOS PROVÁVEL)

**Abordagem**:
1. Conectar C1 via USB
2. Coletar varreduras LIDAR brutas
3. Implementar SLAM 2D próprio (ou usar biblioteca)
4. Gerar mapa de ocupação
5. Aplicar refinamento
6. Exportar PGM/YAML/BMP

**Vantagens**:
- Controle total sobre o processo
- Pode otimizar para nosso caso de uso

**Desvantagens**:
- Mais complexo
- Mais lento
- Requer implementação de SLAM
