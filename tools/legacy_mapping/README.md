# Scripts Legados de Mapas

Esta pasta armazena utilitários antigos de captura e conversão utilizados antes da criação do Aurora Mapping Studio. Eles permanecem apenas como referência histórica e não fazem parte do pipeline final.

Conteúdo atual:
- analisar_stcm.py
- capturar_interface_aurora.py
- converter_bmp_para_mapa.py
- converter_ply_para_mapa.py
- exportar_mapa_aurora.py
- processar_mapa.bat
- teste_aurora_connection.py
- teste_c1_connection.py
- visualizar_mapa.py

Sempre utilize os módulos dentro de `src/aurora_mapping/` e o `main_mapping.py` para qualquer fluxo novo.
